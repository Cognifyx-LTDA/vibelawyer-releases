# Vibe Lawyer — Releases

Feed público de **auto-update** (electron-updater) do **Vibe Lawyer**, da Cognifyx.

Este repositório guarda **apenas os binários** de release (instalador + `latest.yml` + `.blockmap`).
O **código-fonte não fica aqui**.

## Usuários

Baixe a versão mais recente na aba **[Releases](../../releases)**. O app instalado se atualiza sozinho
(ele avisa quando há versão nova).

## Mantenedores

Publicado via `electron-builder --publish always` a partir do repositório do produto.
Passo a passo completo em **`RELEASE.md`** (repo do produto).
